# Contributing

Contributions should be narrowly scoped, tested, and tied to the current official
Technocore manual. Do not include private keys, wallet seeds, access tokens, scraped
room archives, personal data, or claims of reward eligibility.

Before opening a pull request, run the test, lint, type, and build commands in the
README. Explain the protocol invariant affected and link the relevant official source.
Changes that add networking, signing, wallet behavior, or automatic posting require a
separate threat-model review and will not be accepted as incidental refactors.
